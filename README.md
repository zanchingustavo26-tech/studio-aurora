# Studio Aurora — Site demonstrativo

Site institucional fictício para um salão de beleza sofisticado, desenvolvido como projeto de portfólio para praticar desenvolvimento web.

## Sobre o projeto

O Studio Aurora apresenta uma experiência digital elegante, com foco em estética, navegação intuitiva e adaptação para computadores e dispositivos móveis.

## Funcionalidades

- Página inicial com apresentação do studio
- Seção sobre o estabelecimento fictício
- Apresentação dos serviços
- Tabela de preços
- Galeria de imagens
- Depoimentos demonstrativos
- Botões de contato e agendamento via WhatsApp
- Layout responsivo para celular e computador

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Demonstração

**Site publicado:** https://zanchingustavo26-tech.github.io/studio-aurora/

## Objetivo

Este projeto foi desenvolvido para fins de aprendizado e portfólio. O Studio Aurora é uma marca fictícia, e os serviços, preços e depoimentos são demonstrativos.
